# LinqPeldak – LINQ példatár (C# konzol)

44 LINQ-példa a Laptops vizsgafeladat valódi adatain (`forras/laptops.txt`, 325 laptop):
szűrés (Where), rendezés (OrderBy/ThenBy), First/FirstOrDefault, Take/Skip, Count/Sum/Average/Min/Max,
Select, Distinct, GroupBy, ToDictionary, Intersect/Except, query szintaxis, LINQ nélküli (foreach) változat, fájlba írás.

Futtatás: Visual Studióban F5, vagy `dotnet run` a projektmappában.

Magyarázat és az eredmények: [LINQ.md a vizsga-jegyzetekben](https://github.com/Tanarurkedvence/vizsga-jegyzetek/blob/main/LINQ.md)
